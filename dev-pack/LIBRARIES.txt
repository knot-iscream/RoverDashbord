Notes
  The shipped sketches match stable 4.0 except for the dev WiFi preload and
  the broker address written by DEV-START.bat. MQTT topics, payload shapes
  and timings are unchanged, so the app reads them exactly as it reads a
  wired or stable-build board. No compiled binaries are shipped: flash the
  source from Arduino IDE.
